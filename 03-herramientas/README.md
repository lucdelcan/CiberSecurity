# 03 · Herramientas

Notas de uso por herramienta: configuración, opciones útiles y trucos. **No** payloads (eso va en `../04-cheatsheets/`) ni metodología (eso va en `../00-metodologia/`) — aquí va el "cómo manejo esta herramienta".

## Cajones

| Carpeta | Herramienta |
|---|---|
| `burp/` | Burp Suite: configuración, extensiones, macros, scope. |
| `nmap/` | Nmap: flags, scripts NSE, tipos de escaneo. |
| `ffuf-gobuster/` | Fuzzing de contenido y parámetros. |
| `sqlmap/` | Automatización de SQLi. |
| `dast/` | Escáneres DAST (ZAP y otros) del día a día. |
| `custom-scripts/` | Tus propios scripts y one-liners reutilizables. |

## Convención

- Una nota por herramienta con: instalación/config, comandos base, opciones que sueles olvidar, y trucos propios.
