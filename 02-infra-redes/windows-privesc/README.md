# Windows Privilege Escalation

Escalada de privilegios en Windows tras conseguir acceso.

## Temas a cubrir (fichas)

- Enumeración (winpeas, Seatbelt).
- Privilegios de token (SeImpersonate → Potato attacks).
- Servicios mal configurados (unquoted path, permisos débiles).
- AlwaysInstallElevated, tareas programadas.
- Credenciales (SAM, LSASS, DPAPI, ficheros).
- UAC bypass.
