# 05 · Writeups

Aprendizaje documentado: resolución de retos y máquinas, hallazgos de bug bounty, y notas de labs.

## Estructura sugerida

- `ctf/` — retos de CTF por evento.
- `bugbounty/` — hallazgos propios (anonimizados).
- `labs/` — ejercicios y entornos de práctica.

## Reglas

- No publicar writeups de **máquinas activas** de plataformas ni contenido con licencia/copyright de terceros.
- Anonimiza cualquier dato de programas privados o clientes.
- Cada writeup: objetivo, pasos, vulns encontradas (enlaza a la ficha en `../01-web/`), y aprendizajes.
