# Informe

Todo lo relacionado con el reporte al cliente. Cada vez que redactas un buen finding, abstráelo y guárdalo aquí para reutilizar.

## Contenido

- `plantilla-finding.md` — estructura estándar de un hallazgo.
- Guía de scoring CVSS: cómo construyes el vector y justificas la severidad.
- Catálogo de redacciones reutilizables (descripciones, impactos y remediaciones por tipo de vuln).
- Estructura y tono del informe para cliente (resumen ejecutivo, alcance, hallazgos, conclusiones).

## Buenas prácticas de redacción

- Separa **hallazgo técnico** de **riesgo de negocio**.
- La remediación debe ser accionable y concreta, no genérica.
- Evidencia mínima suficiente: que se entienda, sin exponer datos sensibles.
