# WSTG-CONF · Configuration and Deployment Management

- [ ] `WSTG-CONF-01` **Network Infrastructure Config** — Revisar la config de la infra: servicios expuestos y elementos de red mal configurados.
- [ ] `WSTG-CONF-02` **Application Platform Config** — Buscar configuraciones por defecto/inseguras del servidor y framework, ficheros de ejemplo.
- [ ] `WSTG-CONF-03` **File Extensions Handling** — Probar cómo trata extensiones (`.php`, `.bak`, `.inc`) que revelen código o info.
- [ ] `WSTG-CONF-04` **Old Backup & Unreferenced Files** — Buscar backups y ficheros no enlazados (`.bak`, `.old`, `.zip`, `~`).
- [ ] `WSTG-CONF-05` **Admin Interfaces** — Localizar paneles de administración (rutas comunes, referencias en JS).
- [ ] `WSTG-CONF-06` **HTTP Methods** — Probar métodos peligrosos habilitados (PUT, DELETE, TRACE).
- [ ] `WSTG-CONF-07` **HSTS** — Comprobar la cabecera `Strict-Transport-Security`.
- [ ] `WSTG-CONF-08` **RIA Cross Domain Policy** — Revisar `crossdomain.xml` / `clientaccesspolicy.xml` demasiado permisivos.
- [ ] `WSTG-CONF-09` **File Permission** — Revisar permisos de ficheros y directorios sensibles.
- [ ] `WSTG-CONF-10` **Subdomain Takeover** — Buscar subdominios que apuntan a servicios sin reclamar (CNAME colgado).
- [ ] `WSTG-CONF-11` **Cloud Storage** — Buckets S3 / blobs mal configurados y accesibles.
