# WSTG-CLNT · Client-side

- [ ] `WSTG-CLNT-01` **DOM-Based XSS** — XSS que ocurre en el propio JavaScript del cliente.
- [ ] `WSTG-CLNT-02` **JavaScript Execution** — Conseguir ejecución de JS controlada por el atacante.
- [ ] `WSTG-CLNT-03` **HTML Injection** — Inyectar HTML arbitrario en la página.
- [ ] `WSTG-CLNT-04` **Client-side URL Redirect** — Open redirect controlado desde el cliente.
- [ ] `WSTG-CLNT-05` **CSS Injection** — Inyectar CSS (exfiltración de datos, manipulación visual).
- [ ] `WSTG-CLNT-06` **Client-side Resource Manipulation** — Controlar recursos que carga el cliente (scripts, iframes).
- [ ] `WSTG-CLNT-07` **CORS** — Política CORS mal configurada que permite leer datos entre orígenes.
- [ ] `WSTG-CLNT-08` **Cross Site Flashing** — Abuso de contenido Flash (legacy).
- [ ] `WSTG-CLNT-09` **Clickjacking** — Enmarcar la página para engañar los clics (falta `X-Frame-Options`/CSP).
- [ ] `WSTG-CLNT-10` **WebSockets** — Seguridad de WebSockets (validación de origen, cifrado, auth).
- [ ] `WSTG-CLNT-11` **Web Messaging** — `postMessage` inseguro entre orígenes.
- [ ] `WSTG-CLNT-12` **Browser Storage** — Datos sensibles en `localStorage`/`sessionStorage`/IndexedDB.
- [ ] `WSTG-CLNT-13` **Cross Site Script Inclusion (XSSI)** — Robo de datos incluyendo scripts de otro origen.
