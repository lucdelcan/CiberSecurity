# Checklists

Listas accionables que recorres para no dejarte nada. Marca con `- [x]` al completar.

Aquí adaptas la **OWASP WSTG** a tu forma de trabajar y mantienes tu checklist de cierre.

## Antes de cerrar un engagement

- [ ] Revisada toda la superficie mapeada en `enumeration/`.
- [ ] Autenticación y gestión de sesión probadas.
- [ ] Control de acceso (IDOR, privilegios horizontal/vertical).
- [ ] Validación de entrada (inyecciones, XSS, SSRF, XXE...).
- [ ] Lógica de negocio revisada.
- [ ] Configuración y cabeceras de seguridad.
- [ ] Todos los hallazgos tienen PoC y severidad asignada.
- [ ] Evidencias recogidas y anonimizadas.
- [ ] Informe redactado con resumen ejecutivo.

> Descarga la WSTG oficial y trocea sus categorías (INFO, CONF, IDNT, ATHN, ATHZ, SESS, INPV, ERRH, CRYP, BUSL, CLNT, APIT) en checklists propias.
