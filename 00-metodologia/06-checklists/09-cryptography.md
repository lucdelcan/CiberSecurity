# WSTG-CRYP · Weak Cryptography

- [ ] `WSTG-CRYP-01` **Weak TLS** — Versiones o suites de cifrado TLS obsoletas/débiles.
- [ ] `WSTG-CRYP-02` **Padding Oracle** — Descifrar o forjar datos aprovechando un padding oracle.
- [ ] `WSTG-CRYP-03` **Sensitive Info over Unencrypted Channels** — Datos sensibles enviados sin cifrar.
- [ ] `WSTG-CRYP-04` **Weak Encryption** — Algoritmos o implementaciones débiles (ECB, claves embebidas, sin salt).
