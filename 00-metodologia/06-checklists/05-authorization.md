# WSTG-AUTHZ · Authorization

- [ ] `WSTG-AUTHZ-01` **Directory Traversal / File Include** — Path traversal y LFI/RFI para leer ficheros o incluir código.
- [ ] `WSTG-AUTHZ-02` **Bypass Authorization** — Acceder a funciones/recursos sin permiso forzando rutas o parámetros.
- [ ] `WSTG-AUTHZ-03` **Privilege Escalation** — Pasar de usuario normal a privilegiado/admin (escalada vertical).
- [ ] `WSTG-AUTHZ-04` **IDOR** — Acceder a recursos de otros usuarios cambiando identificadores.
