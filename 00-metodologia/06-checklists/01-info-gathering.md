# WSTG-INFO · Information Gathering

Recon y mapeo. Ver proceso en `../01-recon/` y `../02-enumeration/`.

- [ ] `WSTG-INFO-01` **Search Engine Discovery** — Buscar con dorks en Google/Bing información sensible indexada (paneles, ficheros, correos, credenciales).
- [ ] `WSTG-INFO-02` **Fingerprint Web Server** — Identificar servidor web y versión (cabeceras, comportamiento) para buscar vulns conocidas.
- [ ] `WSTG-INFO-03` **Review Webserver Metafiles** — Revisar `robots.txt`, `sitemap.xml`, `security.txt` por rutas e info filtrada.
- [ ] `WSTG-INFO-04` **Enumerate Applications** — Descubrir todas las apps, vhosts y puertos alojados en el servidor.
- [ ] `WSTG-INFO-05` **Review Webpage Content** — Mirar HTML, comentarios y ficheros JS por datos sensibles (claves, rutas, endpoints).
- [ ] `WSTG-INFO-06` **Identify Entry Points** — Mapear todos los puntos de entrada: parámetros, formularios, cabeceras, cookies.
- [ ] `WSTG-INFO-07` **Map Execution Paths** — Recorrer la app (spidering) para entender flujos y funcionalidades.
- [ ] `WSTG-INFO-08` **Fingerprint Framework** — Identificar el framework (cookies, cabeceras, rutas típicas).
- [ ] `WSTG-INFO-09` **Fingerprint Web Application** — Identificar la app/CMS concreto y su versión.
- [ ] `WSTG-INFO-10` **Map Application Architecture** — Entender la arquitectura: WAF, proxies, balanceadores, APIs, terceros.
